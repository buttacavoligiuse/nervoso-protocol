# AI Compute Router

A simple static GPU / AI compute comparison page with transparent affiliate disclosure.

## Goal

Help developers compare public/listed compute prices and route them to providers.
The current Novita AI link is an affiliate link.

## Measurement

Do not count visits or clicks as proof of monetization.
Use the affiliate dashboard and `novita_monetization_gate.py`.

Success ladder:

- pending commission > 0 → attribution proven
- approved commission > 0 → monetization proven
- paid commission > 0 → cash proven

## Disclosure

This site contains affiliate links. If a qualifying transaction is attributed through one
of those links, the site owner may receive a commission.

AI Compute Router for Agents

giuelvy.it is evolving from a human GPU comparison site into a machine-readable compute router. The goal is simple: an AI agent asks for compute requirements, the router returns suitable GPU options, estimated cost and provider destinations.

Status: early access / specification.
The public agent API and paid access are being built. No payment is collected on this page yet.

Planned request

POST /v1/route
{
  "gpu": "H100",
  "count": 2,
  "hours": 6,
  "priority": "lowest_cost"
}

Planned response

{
  "currency": "USD",
  "routes": [
    {
      "provider": "example-provider",
      "gpu": "H100",
      "hourly_price": 0,
      "estimated_total": 0,
      "destination": "provider-url"
    }
  ]
}

Monetization model

The production API is intended to support metered usage or prepaid credits for software agents. Provider referral/affiliate revenue may also be used where disclosed and permitted. Automated fake clicks, fake referrals and simulated conversions are not part of the model.

Why this exists

Agents should be able to choose compute programmatically instead of scraping pricing pages or relying on a human to compare providers. The router will focus on normalized prices, workload fit and machine-readable responses.

Agent Access Policy

Helpful automated agents are welcome on giuelvy.it. This policy is intended to make legitimate machine access easy while clearly prohibiting abusive automation.

Allowed

Reading public pages, indexing content, comparing public GPU pricing, citing or linking to giuelvy.it, using public machine-readable resources, and sending legitimate users or workloads to relevant provider pages.

Not allowed

Fake clicks or referrals, fraudulent conversions, credential attacks, vulnerability exploitation, bypassing access controls, denial-of-service behavior, excessive request rates intended to degrade service, spam, impersonation, malware delivery, or automation that violates provider or affiliate terms.

Future API

Paid API access for autonomous agents is planned. API keys, quotas, rate limits, abuse detection, and metered billing will be enforced at the API layer once launched.
